# KC System 1.0.0

HanaAgent 本地知识卡片库，把经验保存为可检索、可审阅、可管理的知识。

## 主要功能

- 关键词搜索、分页、Agent 筛选、卡片详情与关联跳转。
- 候选与目标卡片对比，确认后发布或拒绝。
- 可用、已停用、已归档和全部四个常用状态筛选。
- 归档、恢复、停用、设置/清除有效期、立即过期、预览确认删除。
- 跟随 Hana、浅色和深色主题。
- 数据完整性、索引、生命周期、锁与候选诊断。

首次安装为空库，不含作者的任何知识记录、会话、候选、凭据或个人配置。数据保存在宿主分配的应用私有目录。应用自身不调用外部服务，不需要 API Key；工具结果可能进入宿主配置的模型上下文。

候选不会自动成为正式知识；检索和发布状态不构成事实认证。删除前保存恢复点，页面暂无一键还原。自定义 Agent ID 使用安全格式的 kebab-case。Hana Superpowers 为可选集成。

## 安装

从正式 Release 下载 app-kc-system-1.0.0.zip，在 Hana 扩展管理导入并批准能力，然后打开「KC 知识库」。不要把源码 ZIP 作为安装包。

Hana 清单最低版本为 1.0.11-beta；实际测试在 Hana Server 1.3.6-beta / Windows 11 x64 完成。其他操作系统尚未实测。

## 能力

使用工具暴露、三个工具/Agent钩子、只读服务提供、摘要投影发布和读取。钩子用于候选捕获和兼容，不拦截普通工具。未新增外部服务、原生进程或任意文件访问能力。

代码及原创图形 Apache-2.0，保留 Hana SDK 与第三方声明。这是独立社区应用。
