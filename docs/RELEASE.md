# KC System 1.0.0

首个公开版本，提供本地知识检索、候选审阅、归档与有效期管理、受控删除、主题切换和诊断。

安装：下载 `app-kc-system-1.0.0.zip`，在 Hana 扩展管理中导入并批准能力。

- `app-kc-system-1.0.0.zip`：可安装的 Hana v2 App。
- `app-kc-system-1.0.0.entry.json`：官方打包元数据，供市场核对身份与哈希。
- `kc-system-1.0.0-source.zip`：干净源码、文档与合成测试，不含 Git 历史。

所有发布包均不含用户知识、候选、会话、凭据或个人配置。首次安装为空库；已有同 ID 应用的数据由宿主保留。独立公开版本为 1.0.0，请勿用它降级已有更高内部版本。

自测与边界详见 docs/TESTING.md。Apache-2.0，保留 SDK 和第三方声明。
