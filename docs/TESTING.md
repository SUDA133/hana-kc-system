# 1.0.0 自测报告

## 环境

- Hana Server 1.3.6-beta，官方作者工具。
- Windows 11，构建 26300，x64。
- 宿主 Node 26.12.1；单元测试 Node 22.23.3。
- 独立 Electron 44.9.0。
- 所有运行测试均使用隔离临时 AppHost 和合成数据，未修改生产知识库。

## 验证范围

最终自动测试共44项：43项通过，0项失败，1项符号链接测试因Windows当前权限不足跳过。包含原有27项、15项自定义Agent及分片边界测试、2项空库及数据根隔离测试。

真实构造257个分片时，读取报告complete=false、total=null，重建索引和删除均拒绝，索引不存在、分片字节保持不变；数据目录不可读时明确报错，不伪装空库。

公开1.0.0副本在官方隔离AppHost中通过15项原页面检查和18项管理交互检查：分页、关键词检索、字面渲染不可信内容、候选对比与确认发布/拒绝、窄屏导航，以及归档、恢复、设置/清除有效期、立即过期、停用、预览确认删除、跨Agent同名保留。夹具只在独立测试副本中注入，不进入源码或安装包。

空数据首启检查确认页面0张卡片，应用后端loaded、页面HTTP200、SDK握手通过，无资源加载失败或渲染异常。

应用管理流程覆盖读取、筛选、候选发布与拒绝、归档、恢复、有效期、停用、受控单卡删除。公开版本补充自定义 Agent 的写入、枚举、检索与路径拒绝测试。

## 最终发布包核验

官方打包器生成 app-kc-system-1.0.0.zip 和匹配 entry.json；对最终ZIP执行官方 --archive --smoke 通过：后端loaded、页面HTTP200、SDK握手passed，资源失败和渲染异常均为0。作者静态检查ERROR 0 / WARN 0。该运行校验不代表所有能力经过故障注入。

源码与安装归档分别按显式允许清单及压缩包条目进行数据文件、凭据模式、个人路径审计；不包含生产运行数据、开发历史或截图。

## 已知边界

- 未在 macOS、Linux 和所有最低版本 Hana 上实测。
- 没有全量故障注入、多客户端压力测试。
- 官方静态校验可能提示 DYNAMIC_DEPENDENCIES_NOT_PROVEN；最终 UI 资源与握手单独通过运行 smoke 核对。
- 删除恢复需人工核对恢复点，页面无一键还原。
- Hana Superpowers 未安装时投影不可用，相关诊断不等于本地库不可用。
- 自动候选捕获依赖宿主结果形状，未覆盖所有异步完成事件。
- 1.0.0 未安装进作者的现有高版本生产应用；安装验证采用最终 Release 同字节 ZIP 的隔离 AppHost。
